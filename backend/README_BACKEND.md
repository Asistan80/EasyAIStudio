\# 🚀 Easy AI Studio Backend



Backend service for Easy AI Studio.



\---



\# Version



```

1.1.0

```



\---



\# Requirements



\- Python 3.11+

\- pip

\- Virtual Environment (recommended)



\---



\# Installation



Clone project



```bash

git clone https://github.com/yourname/EasyAIStudio.git

```



Go backend folder



```bash

cd EasyAIStudio/backend

```



Install packages



```bash

pip install -r requirements.txt

```



\---



\# Run



```bash

python run.py

```



or



```bash

uvicorn main:app --reload

```
